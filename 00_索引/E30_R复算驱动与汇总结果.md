## 2026-11-12：固定R输入的跨积分器比较

【分析/外部知识】实际以R收紧模型coef_cov_tight.csv和tight_slope_cov.csv为唯一系数/协方差输入；断言23行列名一致。Python使用与前批相同的Cholesky联合正态、八次扰乱Sobol各2^18点、种子20261105—20261112，两组分别取max(abs(Z))尾概率；不再重新拟合Python模型，故本步隔离的是固定输入下的积分实现差异。

健康项R=.5278294208，固定输入Python=.5279655457，绝对差.0001361249；Python扰乱均值SE=.0002258463，R23组报告积分error约.00008416045（仍高于目标）。23组最大绝对差.0002115126，在Rhappyvery；其Python扰乱均值SE=.0001216725。五教育组最大差.0000071475，在大学−大专，Python扰乱均值SE=.0000080600，R教育组error约.0000080703。两种误差量不同，不能直接相加作严格置信界或据此保证全部差异只由积分造成。

这完成固定同一输入的两组跨积分器对照；残差处于所报告数值不确定性需要考虑的尺度，尚不能当模型不一致证据或历史真值认证。结合前批，已分别检查拟合精度、完整协方差和固定输入积分三层；历史环境、旧表似然约.3差异仍未闭合，不能称E30所有问题已解决。无新增数据/独立验证。

### 固定输入复算代码

在前述R compare驱动完成后另执行 `write.csv(multcomp:::polrvcov(refit),"tight_slope_cov.csv")`，并保留coef_cov_tight.csv。下列Python依赖NumPy/pandas/SciPy；把rpath所用输入目录调整为本机临时工作目录。示例中工作区依赖路径是本次环境记录，需按本机已安装依赖调整，不保证任意机器开箱运行。

```python
import os,json,sys
from pathlib import Path
sys.path.insert(0,str(Path('tmp/e30_deps').resolve()))
import numpy as np,pandas as pd
from scipy.stats import qmc,norm
w=Path(os.environ['TEMP'])/'relationship-r-audit'
b=pd.read_csv(w/'coef_cov_tight.csv');v=pd.read_csv(w/'tight_slope_cov.csv',index_col=0)
assert list(v.columns)==list(b.term)==list(v.index)
beta=b.beta.to_numpy();cov=v.to_numpy();out={}
for name,K in [('slopes',np.eye(23)),('education',None)]:
 if K is None:
  K=np.zeros((5,23));K[0,6]=-1
  for j in range(1,5):K[j,5+j]=1;K[j,6+j]=-1
 est=K@beta;vc=K@cov@K.T;se=np.sqrt(np.diag(vc));cr=vc/np.outer(se,se);L=np.linalg.cholesky(cr);z=np.abs(est/se);runs=[]
 for seed in range(20261105,20261113):
  x=norm.ppf(qmc.Sobol(len(z),scramble=True,seed=seed).random_base2(18))@L.T;m=np.max(np.abs(x),axis=1);runs.append([(m>=q).mean() for q in z])
 a=np.array(runs);out[name]={'p':a.mean(0).tolist(),'replicate_mean_SE':(a.std(0,ddof=1)/np.sqrt(8)).tolist()}
Path('tmp/e30_fixed_R_QMC_20261112.json').write_text(json.dumps(out,indent=2));print(json.dumps(out),flush=True)


```
