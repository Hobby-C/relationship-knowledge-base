## 2026-11-12：固定R输入的跨积分器比较

【分析/外部知识】实际以R收紧模型coef_cov_tight.csv和tight_slope_cov.csv为唯一系数/协方差输入；断言23行列名一致。Python使用与前批相同的Cholesky联合正态、八次扰乱Sobol各2^18点、种子20261105—20261112，两组分别取max(abs(Z))尾概率；不再重新拟合Python模型，故本步隔离的是固定输入下的积分实现差异。

健康项R=.5278294208，固定输入Python=.5279655457，绝对差.0001361249；Python扰乱均值SE=.0002258463，R23组报告积分error约.00008416045（仍高于目标）。23组最大绝对差.0002115126，在Rhappyvery；其Python扰乱均值SE=.0001216725。五教育组最大差.0000071475，在大学−大专，Python扰乱均值SE=.0000080600，R教育组error约.0000080703。两种误差量不同，不能直接相加作严格置信界或据此保证全部差异只由积分造成。

这完成固定同一输入的两组跨积分器对照；残差处于所报告数值不确定性需要考虑的尺度，尚不能当模型不一致证据或历史真值认证。结合前批，已分别检查拟合精度、完整协方差和固定输入积分三层；历史环境、旧表似然约.3差异仍未闭合，不能称E30所有问题已解决。无新增数据/独立验证。

## 2026-11-16：固定R输入2^22点/序列的分批积分驱动

【分析/外部知识】本节为实际执行的本库Python脚本。输入同前R聚合系数/协方差CSV，指纹及假设见[E30末节](E30_伴侣收入高潮频率与正式更正边界.md)。只重算23斜率检验族；环境：{"numpy":"2.3.5","pandas":"3.0.1","scipy":"1.18.1"}。八种子、每条64批×65536＝2^22点，总33554432点。分批保持同一Sobol生成器状态，不在每批重置种子。旧2^18与新2^22不是16次独立重复。

```python
import os,sys,json,hashlib,time
from pathlib import Path
os.environ['OPENBLAS_NUM_THREADS']='1'
sys.path.insert(0,str(Path('tmp/e30_deps').resolve()))
import numpy as np,pandas as pd
from scipy.stats import qmc,norm
w=Path(os.environ['TEMP'])/'relationship-r-audit'; bp=w/'coef_cov_tight.csv'; vp=w/'tight_slope_cov.csv'
b=pd.read_csv(bp);v=pd.read_csv(vp,index_col=0);assert list(v.columns)==list(b.term)==list(v.index)
beta=b.beta.to_numpy();cov=v.to_numpy();est=beta;se=np.sqrt(np.diag(cov));L=np.linalg.cholesky(cov/np.outer(se,se));z=np.abs(est/se)
runs=[];start=time.time()
for seed in range(20261105,20261113):
 sampler=qmc.Sobol(23,scramble=True,seed=seed); counts=np.zeros(23,dtype=np.int64)
 for _ in range(64):
  u=sampler.random(65536);m=np.sort(np.max(np.abs(norm.ppf(u)@L.T),axis=1));counts+=len(m)-np.searchsorted(m,z,side='left')
 runs.append((counts/(2**22)).tolist());print('seed',seed,'elapsed',time.time()-start,flush=True)
a=np.array(runs);out={'input_sha256':{p.name:hashlib.sha256(p.read_bytes()).hexdigest() for p in [bp,vp]},'seeds':list(range(20261105,20261113)),'points_per_seed':2**22,'total_points':8*2**22,'terms':b.term.tolist(),'p':a.mean(0).tolist(),'replicate_mean_SE':(a.std(0,ddof=1)/np.sqrt(8)).tolist(),'replicates':runs,'elapsed_seconds':time.time()-start,'numpy':np.__version__}
Path('tmp/e30_fixed_R_QMC22_20261116.json').write_text(json.dumps(out,indent=2),encoding='utf8')
print(json.dumps(out),flush=True)
```
