## 指定两水平总体效应【分析】

用每人的两次均值A=(T1+T2)/2、变化D=T2−T1，并按组汇总；两组差值的等方差独立t²对应交互，两组A的独立t²对应组效应。时间效应用两个组D均值的等权边际平均及其合并残差方差。三项df均为(1,163)，未重跑其他四类/比例模型或完整统计软件流程。

| 项 | 本批F | 论文F | 对应范围 |
|---|---:|---:|---|
| Group | 781.060115 | 781.06 | 指定总体模型组效应 |
| Time | 161.771660 | 161.77 | 指定总体模型时间效应 |
| Group×Time | 117.884647 | 117.89 | 绝对差0.005353；常规两位小数为117.88，保留小数差，不记完全相等 |

本批没有独立重算全部p值、置信区间、校正检验或所有模型。指定结果近似一致不证明影片、回忆原件、编码过程及全部研究结论均已独立核实。

最小复算步骤（读取原SPSS；本批读取器pyreadstat 1.3.7）：

```python
import pyreadstat
p, meta = pyreadstat.read_sav('Data_Krixetal_Consistency_Beliefs.sav')
assert p.SUBJNR.is_unique
cols = ['XDesc1Acc','XDesc2Acc','XDescConsAcc','XDescRemAcc','XDescInco2Acc']
print(p.groupby('GROUP')[cols].agg(['count','mean','std']))
p['D'] = p.XDesc2Acc - p.XDesc1Acc
p['A'] = (p.XDesc1Acc + p.XDesc2Acc)/2
a, b = p[p.GROUP.eq(0)], p[p.GROUP.eq(1)]
df = len(a) + len(b) - 2
for col in ['D','A']:
    sp = ((len(a)-1)*a[col].var(ddof=1)+(len(b)-1)*b[col].var(ddof=1))/df
    F = (a[col].mean()-b[col].mean())**2/(sp*(1/len(a)+1/len(b)))
    print(col, F, df)
    if col == 'D':
        print('Time F', ((a.D.mean()+b.D.mean())/2)**2/(sp*(1/len(a)+1/len(b))/4))
m = p[p.GROUP.eq(1)]
print(m[['XDescRemQan','XDescInco2Qan','XDesc2Acc','XDesc2NoIncoAcc']].corr())
```
