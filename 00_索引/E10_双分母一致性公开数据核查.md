## 完整案例与交互复算【分析】

每种指标分别删去其high/low比例任一缺失的行；不对两指标先统一删行。下面均是完整案例均值，非各列独立删缺后的边际均值。

|---|---:|---:|---:|---:|

| repetition，experienced | 134 | 0.867565 | 0.450635 | 0.416930 |

两水平组内因素的交互，用每行high−low差值作两独立组等方差t检验，取t²作为F；retention得5.288198、df=266，repetition得41.586800、df=264，与论文可读段四舍五入的5.29/41.59相符。本批未运行完整ANOVA/全部效应、p值/置信区间、分布检验或分类器，不把相符扩大为整篇模型复现。

可重做最小步骤（源CSV不改写）：

```python
import pandas as pd
p = pd.read_csv('data_differential_mnemonic_consistency.csv')
for kind in ['retention', 'repetition']:
    h, l = [f'P_{kind}_consistency_{x}' for x in ['high', 'low']]
    d = p.dropna(subset=[h, l]).copy()
    d['delta'] = d[h] - d[l]
    a = d.loc[d.Group.eq('experienced incident'), 'delta']
    b = d.loc[d.Group.eq('fabricated incident'), 'delta']
    df = len(a) + len(b) - 2
    pooled = ((len(a)-1)*a.var(ddof=1) + (len(b)-1)*b.var(ddof=1))/df
    F = (a.mean()-b.mean())**2 / (pooled*(1/len(a)+1/len(b)))
    print(kind, len(d), df, F, d.groupby('Group')[[h,l,'delta']].mean())
```

## 【跨资料归纳】应用边界

同称“一致性”可因分母不同出现不同总体方向；这不能合成“越一致越真”或“越一致越假”。两个组间平均差/交互不是现实某人说谎概率，也没有由本批建立个人阈值。此研究扩展Lange等2020，与E04短问答程序不是已核的直接复现关系；先保留测量差异，后查独立材料/验证。
