# E70 囚徒困境收益结构与关系类比边界

更新：2026-11-03。本条含理论出处核查及原书数字的确定性推导，不是关系行为调查。

【原资料观点】B16《当我们都已成为过往的囚徒》，`OEBPS/text00005.html#mllj17`至mllj18，全文含RAND TIPS已重读。源SHA-256：`f9676d84b828407a0f69275f49ca262bc5e007ca30788c268c90fd0c1f28cb64`。作者把秘密恋情中的不信任类比囚徒困境，并推测成年人多选择相互背叛。个人叙述只按书中叙述收录，不证明第三方真实婚姻状态或动机。首读不增。

【外部知识】Holt与Roth（2004），*The Nash equilibrium: A perspective*，PNAS 101(12):3999—4002，DOI [10.1073/pnas.0308738101](https://doi.org/10.1073/pnas.0308738101)。实际读[期刊网页摘要、均衡概念与社会困境章节](https://www.pnas.org/doi/full/10.1073/pnas.0308738101)，未复核其所有引文和实验。文中区分1950年1月Dresher与Flood在RAND所做实验，以及Tucker后来设计的囚徒故事；不是几名RAND专家一次写成全部故事。均衡要求各自对他人策略作最佳回应，不是全体福利最优，也不保证现实参与者必然照做；初始及后续实验会出现合作。

另读[实验经济学中心EconPort该题教学页正文](https://econport.gsu.edu/content/handbook/gametheory/experiment/prisoner.html)，用于核对一次与重复互动的概念区别；未执行其链接实验或重做锦标赛。重复互动的策略可依历史变化，不能把一次博弈预测无条件搬入反复交往。

【分析：用原书给定刑期推导】先额外假设两人只在意自身刑期且越短越好，以负刑期表示效用；C=沉默、D=指认。数字不是实际量表或法律判刑规则。

| 自己\对方 | C | D |
| --- | --- | --- |
| C | −0.5，−0.5 | −10，0 |
| D | 0，−10 | −2，−2 |

每格先自己后对方。若对方C，自己D的0优于C的−0.5；若对方D，自己D的−2优于C的−10。因此D在本设定严格占优，D/D为唯一纳什均衡；而C/C的两人结果均优于D/D。对应T=0、R=−0.5、P=−2、S=−10，满足T>R>P>S。此为四种情形逐格推导，没有运行真人实验或估计恋人收益。

现实恋情还可能包含诚实偏好、尊严、安全、退出选项、多方承诺、不对称信息及后续互动。若不能确认行动集合、收益次序和互动结构，就只能称类比；“有过去的人大多背叛”需要样本和行为证据，不能由矩阵推出。模型也不要求伤害、试探或欺骗伴侣来避免吃亏。
